## 🚀 Featured Projects

### 🎤 AI Interview Platform
Real-time AI interviewing platform that runs automated technical interviews with live video, speech recognition, and questions generated from the candidate's resume.

- Parses PDF resumes with **LangChain + OpenRouter**, with automatic fallback across 4 LLMs (Gemini, Llama, Qwen, Mistral) to handle rate limits
- Live video/audio using **WebRTC** and bi-directional messaging via **Socket.io**
- HR dashboard with live transcription and automated candidate scoring
- JWT-based role access (Candidate, HR Recruiter) with MongoDB / in-memory fallback

`React` `Node.js` `Socket.io` `WebRTC` `LangChain`

[🌐 Live Demo](https://ai-interviewer-platform-1.onrender.com/login) · [💻 Source Code](https://github.com/Mayank-144/Ai_interviewer_Platform)

### 🏠 PropEase — Real Estate Platform
Full-stack MERN platform connecting property seekers, owners and admins through real-time inquiries, listings and secure payments.

- 11+ REST API endpoints, JWT auth with Bcrypt hashing, role-based access (User, Admin)
- Real-time inquiry and notification system with **Socket.io**
- Image uploads via **Cloudinary + Multer**, payments via **Razorpay**
- Admin panel with full CRUD across Users, Properties, Bookings and Messages

`React` `Node.js` `Express` `MongoDB` `Socket.io` `JWT`

[🌐 Live Demo](https://prop-ease-tau.vercel.app/) · [💻 Source Code](https://github.com/Mayank-144/PropEase)
